# Записная книжка контактов

**Учебный проект — вариант 14**

## Описание

«Записная книжка контактов» — мобильное приложение для Android, разработанное в Android Studio на языке Kotlin с использованием Jetpack Compose.

## Возможности приложения

- Добавление контактов.
- Просмотр списка сохранённых контактов.
- Поиск контактов.
- Сохранение данных между запусками приложения.

## Используемые технологии

- Kotlin
- Jetpack Compose
- Android Studio
- SharedPreferences и JSON

## Установка приложения

Для установки на Android-смартфон скачайте файл `app-debug.apk` из репозитория и откройте его на телефоне.

## Исходный проект

Архив `ContactBook.zip` содержит проект для открытия в Android Studio.
