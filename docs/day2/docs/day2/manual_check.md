# Результаты ручной проверки приложения

## День 3. Вариант 14

**Название проекта:** Записная книжка контактов

**Платформа:** Android

**Язык программирования:** Kotlin

**Среда разработки:** Android Studio

## 1. Цель проверки

Проверить работоспособность основных функций мобильного приложения «Записная книжка контактов»: добавление, просмотр, поиск, удаление и сохранение контактов.

## 2. Результаты тестирования

| № | Проверяемая функция | Ожидаемый результат | Фактический результат | Статус |
|---|---|---|---|---|
| 1 | Запуск приложения | Открывается главный экран | Главный экран открылся | Успешно |
| 2 | Добавление контакта | Новый контакт появляется в списке | Контакт «анна» добавлен | Успешно |
| 3 | Просмотр контактов | Отображаются имя и телефон | Имя и номер отображаются | Успешно |
| 4 | Поиск по имени | Отображается подходящий контакт | По запросу «анна» контакт найден | Успешно |
| 5 | Удаление контакта | Контакт исчезает из списка | Контакт удалён | Успешно |
| 6 | Пустой список | Появляется сообщение об отсутствии контактов | Отображается «Контакты не найдены»
