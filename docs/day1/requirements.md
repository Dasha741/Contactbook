# Требования к мобильному приложению по методу MoSCoW

**Название проекта:** «Записная книжка контактов».

**Вариант:** 14.

## 1. Цель проекта

Разработка мобильного приложения для хранения, просмотра, поиска и удаления контактов на устройствах под управлением Android.

## 2. Приоритизация требований

| Категория | Требование | Статус |
|---|---|---|
| Must have | Добавление новых контактов | Реализовано |
| Must have | Просмотр списка контактов | Реализовано |
| Must have | Удаление контактов | Реализовано |
| Must have | Поиск по имени | Реализовано |
| Must have | Локальное хранение данных | Реализовано |
| Must have | Проверка корректности вводимых данных | Реализовано |
| Should have | Поиск по номеру телефона | Реализовано |
| Should have | Удобный пользовательский интерфейс | Реализовано |
| Should have | Работа без подключения к интернету | Реализовано |
| Could have | Редактирование существующих контактов | Перспектива развития |
| Could have | Сортировка контактов по алфавиту | Перспектива развития |
| Could have | Добавление фотографий контактов | Перспектива развития |
| Won't have | Облачная синхронизация | Не входит в текущую версию |
| Won't have | Регистрация и авторизация пользователей | Не входит в текущую версию |

## 3. Расшифровка категорий MoSCoW

- Must have — обязательные требования.
- Should have — важные требования.
- Could have — дополнительные возможности.
- Won't have — функции, не входящие в текущую версию проекта.

## 4. Нефункциональные требования

- Поддержка Android 8.0 и выше.
- Понятный пользовательский интерфейс.
- Сохранение данных после перезапуска приложения.
- Возможность автономной работы.
- Отсутствие необходимости подключения к внешнему серверу.
- Корректная обработка недопустимых входных данных.

## 5. Вывод

Выполнена приоритизация требований к мобильному приложению «Записная книжка контактов» по методу MoSCoW. Определены обязательные и дополнительные функции, а также перспективы дальнейшего развития проекта. Все требования категории Must have реализованы.
