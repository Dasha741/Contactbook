# Техническое задание (ТЗ v1)

**Тема:** Мобильное приложение «Записная книжка контактов».

**Вариант:** 14.

**Разработчик:** Пекина Дарья Алексеевна.

## 1. Цель приложения

Разработать мобильное приложение для устройств под управлением Android, предназначенное для хранения, просмотра, поиска и удаления контактных данных пользователя.

## 2. Целевые пользователи

Пользователи мобильных устройств под управлением Android, которым необходимо хранить имена и номера телефонов, быстро находить нужные контакты и пользоваться записной книжкой без подключения к интернету.

## 3. Функции Must / Should / Could

### Must — обязательные функции

- Добавление контактов с указанием имени и номера телефона.
- Просмотр списка контактов.
- Удаление контактов.
- Поиск контактов по имени.
- Локальное сохранение контактных данных.
- Проверка корректности вводимых данных.

### Should — желательные функции

- Поиск контактов по номеру телефона.
- Работа без подключения к интернету.
- Отображение сообщения при отсутствии контактов или результатов поиска.

### Could — дополнительные функции

- Редактирование существующих контактов.
- Сортировка контактов по алфавиту.

Дополнительные функции не входят в обязательный объём текущей версии приложения.

## 4. Ограничения

| Параметр | Ограничение |
|---|---|
| Язык программирования | Kotlin |
| Среда разработки | Android Studio |
| Операционная система | Android 8.0 и выше |
| Пользовательский интерфейс | Jetpack Compose |
| Хранение данных | SharedPreferences, JSON |
| База данных | Отдельная СУБД не используется |
| API | Внешние API не используются |
| Формат контактных данных | Имя и номер телефона |
| Номер телефона | 11 цифр |
| Система контроля версий | Git, GitHub |

## 5. Критерии приёмки

| № | Критерий приёмки |
|---|---|
| 1 | Приложение успешно собирается, устанавливается и запускается на Android-устройстве. |
| 2 | Пользователь может добавить контакт с корректными данными. |
| 3 | Сохранённые контакты отображаются в списке. |
| 4 | Поиск по имени возвращает соответствующие контакты. |
| 5 | Пользователь может удалить контакт. |
| 6 | Контакты сохраняются после перезапуска приложения. |
| 7 | Сохранение контакта с пустым именем или некорректным номером телефона недоступно. |
| 8 | Основные функции приложения работают без подключения к интернету. |
