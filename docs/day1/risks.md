# Реестр рисков проекта

**Проект:** «Записная книжка контактов».

**Вариант:** 14.

| № | Риск | Меры реагирования |
|---|---|---|
| 1 | Ошибки сборки приложения | Проверка настроек Gradle и Android Studio, устранение ошибок сборки. |
| 2 | Потеря исходного кода | Регулярное сохранение изменений в GitHub и создание резервных копий. |
| 3 | Потеря сохранённых контактов | Проверка сохранения данных после перезапуска приложения. |
| 4 | Некорректный ввод данных | Валидация имени и номера телефона, тестирование ошибочного ввода. |
| 5 | Нарушение сроков разработки | Соблюдение календарного плана и первоочередная реализация обязательных функций. |
