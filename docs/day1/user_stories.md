# Пользовательские истории (User Stories)

## Мобильное приложение «Записная книжка контактов»

**Вариант:** 14.

**Цель проекта:** разработка мобильного приложения для удобного хранения, поиска и управления контактами пользователя.

## 1. Пользовательские истории

| ID | Пользовательская история | Критерий приёмки | Приоритет |
|---|---|---|---|
| US-01 | Как пользователь, я хочу добавлять новые контакты, чтобы сохранять имена и номера телефонов. | После ввода корректных данных контакт появляется в списке. | Высокий |
| US-02 | Как пользователь, я хочу просматривать список сохранённых контактов. | На главном экране отображаются имена и номера телефонов. | Высокий |
| US-03 | Как пользователь, я хочу искать контакты по имени, чтобы быстро находить нужного человека. | Отображаются контакты, соответствующие поисковому запросу. | Высокий |
| US-04 | Как пользователь, я хочу искать контакты по номеру телефона. | Поиск работает по полному или частичному номеру телефона. | Высокий |
| US-05 | Как пользователь, я хочу удалять ненужные контакты. | Удалённый контакт исчезает из списка. | Высокий |
| US-06 | Как пользователь, я хочу сохранять контакты после закрытия приложения. | После повторного запуска сохранённые контакты остаются доступными. | Высокий |
| US-07 | Как пользователь, я хочу, чтобы приложение проверяло корректность введённых данных. | Сохранение недоступно при пустом имени или некорректном номере телефона. | Высокий |
| US-08 | Как пользователь, я хочу пользоваться записной книжкой без подключения к интернету. | Основные функции приложения доступны в автономном режиме. | Высокий |

## 2. Общие критерии приёмки

- Приложение запускается на устройстве под управлением Android.
- Пользователь может добавлять, просматривать, искать и удалять контакты.
- Номер телефона должен содержать 11 цифр.
- Данные сохраняются в локальном хранилище.
- Поиск по имени выполняется без учёта регистра.
- Основные функции доступны без подключения к интернету.
- Интерфейс обеспечивает удобное взаимодействие с приложением.

## 3. Используемые технологии

- Android Studio — среда разработки.
- Kotlin — язык программирования.
- Jetpack Compose — разработка пользовательского интерфейса.
- SharedPreferences и JSON — локальное хранение данных.
- GitHub — хранение исходного кода и документации.
- JUnit — модульное тестирование.

## 4. Вывод

Сформулированы восемь пользовательских историй, определяющих основные функциональные требования к мобильному приложению «Записная книжка контактов». Для каждой истории установлены критерии приёмки и приоритет реализации. Пользовательские истории соответствуют основным возможностям разработанного приложения по варианту 14.
