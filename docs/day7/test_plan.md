# День 7. Тест-план

## 1. Название проекта
Записная книжка контактов (вариант 14).

## 2. Цель тестирования
Проверить работоспособность приложения,
выявить ошибки и проверить корректность
обработки пользовательских данных.

## 3. Окружение
- Устройство: Realme RMX3472.
- Операционная система: Android.
- Среда разработки: Android Studio.
- Язык программирования: Kotlin.
- Интерфейс: Jetpack Compose.
- Хранение данных: SharedPreferences и JSON.

## 4. Сценарии тестирования
1. Запуск приложения.
2. Добавление контакта.
3. Поиск существующего контакта.
4. Поиск несуществующего контакта.
5. Удаление контакта.
6. Сохранение данных после перезапуска.
7. Проверка пустых полей.
8. Проверка короткого номера телефона.
9. Проверка букв в номере телефона.
10. Проверка длинного имени.
11. Работа приложения без интернета.
12. Повторное нажатие кнопки сохранения.

## 5. Методы тестирования
- Ручное функциональное тестирование.
- Метод черного ящика.
- Модульное тестирование (JUnit).
- Повторное тестирование после исправлений.

## 6. Критерии завершения
- Выполнены все тест-кейсы.
- Зафиксированы обнаруженные дефекты.
- Исправлены критические ошибки.
- Написаны и запущены unit-тесты.
- Подготовлена итоговая таблица результатов.
