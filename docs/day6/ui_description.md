# День 6. Разработка мобильного интерфейса

## Проект
Записная книжка контактов (вариант 14).

## Цель
Разработать пользовательский интерфейс Android-приложения и связать его с логикой управления контактами.

## Основные состояния интерфейса
1. Главный экран «Мои контакты» — список сохранённых контактов, поле поиска и кнопка «Добавить контакт».
2. Окно «Новый контакт» — поля «Имя» и «Телефон», кнопки «Отмена» и «Сохранить».
3. Результаты поиска — отображение контактов, подходящих под введённое имя.
4. Пустое состояние — сообщение «Контакты не найдены», если совпадений нет.

## Навигация
С главного экрана пользователь открывает окно добавления контакта. После сохранения возвращается к списку. Поиск выполняется на главном экране. Удаление контакта выполняется кнопкой «Удалить».

## Реализация
Приложение разработано на Kotlin с использованием Jetpack Compose. Контакты сохраняются локально с помощью SharedPreferences и JSON.

## Проверка
- Добавление контакта — успешно.
- Поиск по имени — успешно.
- Удаление контакта — успешно.
- Сохранение после перезапуска — успешно.
- Пустые поля — сохранение недоступно.
- Номер из трёх цифр — сохранение недоступно.
- Номер из 11 цифр — сохранение доступно.
- Поиск без совпадений — отображается сообщение «Контакты не найдены».
