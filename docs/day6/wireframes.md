# Макеты пользовательского интерфейса (Wireframes)

**Проект:** «Записная книжка контактов».

**Вариант:** 14.

## 1. Главный экран

```
+--------------------------------+
|         Мои контакты           |
|                                |
| [ Поиск контакта             ] |
|                                |
|     [ Добавить контакт ]       |
|                                |
| Анна                           |
| 89001234567                    |
|                   [ Удалить ]  |
|                                |
| Мария                          |
| 89005554433                    |
|                   [ Удалить ]  |
+--------------------------------+
```

Назначение: просмотр списка, поиск, добавление и удаление контактов.

## 2. Окно добавления контакта

```
+--------------------------------+
|         Новый контакт          |
|                                |
| Имя                            |
| [                            ] |
|                                |
| Телефон                        |
| [                            ] |
|                                |
| [ Отмена ]       [ Сохранить ] |
+--------------------------------+
```

Назначение: ввод имени и номера телефона нового контакта.

## 3. Результаты поиска

```
+--------------------------------+
|         Мои контакты           |
|                                |
| [ Поиск контакта: Анна       ] |
|                                |
|     [ Добавить контакт ]       |
|                                |
| Анна                           |
| 89001234567                    |
|                   [ Удалить ]  |
+--------------------------------+
```

Назначение: отображение контактов, соответствующих поисковому запросу.

## 4. Пустое состояние

```
+--------------------------------+
|         Мои контакты           |
|                                |
| [ Поиск контакта             ] |
|                                |
|     [ Добавить контакт ]       |
|                                |
|      Контакты не найдены       |
|                                |
+--------------------------------+
```

Назначение: отображение сообщения при отсутствии контактов или результатов поиска.

## Навигация

С главного экрана пользователь открывает окно добавления контакта. После сохранения или отмены пользователь возвращается к списку контактов. Поиск и удаление выполняются на главном экране.

Макеты отражают реализованный интерфейс приложения.
