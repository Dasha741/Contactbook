# Руководство пользователя

## 1. Общая информация

Название приложения: «Записная книжка контактов».

Вариант: 14.

Приложение предназначено для хранения, добавления, поиска и удаления контактов на мобильных устройствах под управлением Android.

## 2. Установка приложения

1. Скачать файл app-debug.apk из репозитория GitHub.
2. Перенести APK-файл на мобильное устройство.
3. Открыть скачанный файл.
4. При необходимости разрешить установку приложений из данного источника.
5. Нажать кнопку «Установить».
6. После завершения установки открыть приложение.

## 3. Основные экраны

В приложении предусмотрены следующие состояния интерфейса:

- Главный экран со списком контактов.
- Диалог добавления нового контакта.
- Результаты поиска контактов.
- Пустой список контактов.
- Отсутствие результатов поиска.

## 4. Добавление контакта

1. Запустить приложение.
2. Нажать кнопку добавления контакта.
3. Ввести имя контакта.
4. Ввести номер телефона из 11 цифр.
5. Нажать кнопку сохранения.
6. Убедиться, что контакт появился в списке.

## 5. Поиск контакта

1. Открыть главный экран приложения.
2. Ввести имя или номер телефона в строку поиска.
3. Просмотреть найденные контакты.

Поиск по имени выполняется без учёта регистра.

Для отображения полного списка необходимо очистить строку поиска.

## 6. Удаление контакта

1. Найти необходимый контакт в списке.
2. Нажать кнопку удаления соответствующего контакта.
3. Убедиться, что контакт исчез из списка.

## 7. Хранение данных

Контакты сохраняются в локальном хранилище устройства.

При закрытии и повторном запуске приложения сохранённые контакты остаются доступными.

Для основных функций приложения подключение к Интернету не требуется.

## 8. Возможные ошибки и способы их устранения

| Проблема | Решение |
|---|---|
| Неактивна кнопка сохранения | Проверить заполнение имени и номера телефона |
| Номер телефона слишком короткий | Ввести 11 цифр |
| Номер содержит буквы | Заменить буквы цифрами |
| Контакт не найден | Проверить правильность поискового запроса |
| Не отображается полный список | Очистить строку поиска |
| APK-файл не устанавливается | Проверить разрешение на установку из данного источника |
