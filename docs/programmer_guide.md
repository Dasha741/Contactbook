# Руководство программиста

## 1. Общая информация

Название проекта: «Записная книжка контактов».

Вариант: 14.

Тип приложения: мобильное приложение для Android.

Название проекта в Android Studio: ContactBook.

Пакет приложения: com.example.contactbook.

## 2. Используемые технологии и зависимости

- Kotlin — язык программирования.
- Android Studio — среда разработки.
- Jetpack Compose — создание пользовательского интерфейса.
- Material 3 — компоненты пользовательского интерфейса.
- SharedPreferences — локальное хранение данных.
- JSON — формат представления сохранённых контактов.
- Gradle — система сборки проекта.
- JUnit — автоматическое модульное тестирование.
- GitHub — хранение исходного кода и документации.

Зависимости проекта управляются средствами Gradle.

## 4. Архитектура приложения

Приложение состоит из следующих логических частей:

- Пользовательский интерфейс.
- Логика обработки контактов.
- Проверка введённых данных.
- Локальное хранение информации.

Пользователь взаимодействует с интерфейсом, после чего выполняется обработка данных и при необходимости их сохранение.

## 5. Модель данных

Для представления контакта используется класс Contact.

Контакт содержит три поля:

- id — уникальный идентификатор.
- name — имя контакта.
- phone — номер телефона.

Контакты сохраняются в формате JSON с использованием SharedPreferences.

## 6. Основные функции

| Функция | Назначение |
|---|---|
| isValidName | Проверка имени контакта |
| isValidPhone | Проверка номера телефона |
| searchContacts | Поиск контактов по имени или телефону |
| getNextId | Получение следующего идентификатора |

Имя контакта не должно быть пустым или состоять только из пробелов.

Номер телефона должен содержать 11 цифр.

## 7. Сборка приложения

1. Скачать исходный проект.
2. Открыть проект ContactBook в Android Studio.
3. Выполнить синхронизацию Gradle.
4. Дождаться загрузки необходимых зависимостей.
5. Подключить Android-устройство или запустить эмулятор.
6. Выполнить запуск приложения.

Для сборки APK через терминал Windows используется команда:

```powershell
.\gradlew.bat :app:assembleDebug
```

Путь к сформированному APK-файлу:

app/build/outputs/apk/debug/app-debug.apk

## 8. Запуск автоматических тестов

Для запуска модульных тестов используется команда:

```powershell
.\gradlew.bat :app:testDebugUnitTest
```

При возникновении ошибки загрузки GradleWorkerMain можно использовать альтернативную папку кэша Gradle:

```powershell
$env:GRADLE_USER_HOME = "C:\GradleCache"
.\gradlew.bat :app:testDebugUnitTest --no-configuration-cache
```

Настройка действует в текущем сеансе терминала.

Для просмотра HTML-отчёта используется команда:

```powershell
Start-Process ".\app\build\reports\tests\testDebugUnitTest\index.html"
```
