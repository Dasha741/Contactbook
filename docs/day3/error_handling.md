# Обработка ошибок

**Проект:** «Записная книжка контактов».

**Вариант:** 14.

## 1. Цель

Обеспечить корректную работу приложения при некорректном вводе данных и отсутствии контактов.

## 2. Таблица ошибок и реакций

| № | Ошибочная ситуация | Реакция приложения | Результат проверки |
|---|---|---|---|
| 1 | Пустое имя контакта | Кнопка сохранения недоступна | Успешно |
| 2 | Номер телефона содержит менее 11 цифр | Сохранение контакта недоступно | Успешно |
| 3 | Номер телефона содержит буквы | Некорректный номер не проходит валидацию | Успешно |
| 4 | Отсутствуют результаты поиска | Отображается сообщение «Контакты не найдены» | Успешно |
| 5 | Отсутствуют сохранённые контакты | Отображается пустое состояние списка | Успешно |

## 3. Работа без подключения к интернету

Приложение использует локальное хранение данных. Отсутствие подключения к интернету не препятствует выполнению основных операций.

## 4. Вывод

Реализована проверка корректности вводимых данных и обработка пустых состояний. Проверенные сценарии выполняются корректно.
